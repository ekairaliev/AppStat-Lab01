# COLOR LAB — лабораторная по прикладной статистике

**Тема:** яркость и насыщенность цифровых изображений CIFAR-10.

Проект содержит самостоятельный интерактивный сайт **на marimo**, исходный Colab-ноутбук, CSV с характеристиками 10 000 тестовых изображений и 200 настоящих фотографий для демонстрации.

## Самый простой запуск на Windows

1. Распакуйте ZIP через **«Извлечь всё»**.
2. Откройте папку, **в которой лежит `photo_app.py`**. Не нужно искать вложенную папку `COLOR_LAB` — в данном архиве файл находится в корне.
3. Первый раз запустите `INSTALL_LIBRARIES.bat` (или используйте команду ниже).
4. Запустите `START_COLOR_LAB.bat`. Откроется браузер с сайтом.

Если Windows не разрешает запуск `.bat`, нажмите на адресную строку Проводника в этой же папке, введите `cmd`, нажмите Enter и выполните:

```cmd
py -m pip install -r requirements.txt
py -m marimo run photo_app.py
```

**Не используйте `marimo edit` для просмотра готового сайта:** он открывает интерфейс редактирования с кодом.

> Адрес `localhost` работает только на компьютере, где запущен Python. Загрузка файлов в GitHub сама по себе НЕ делает приложение marimo доступным по публичной ссылке GitHub Pages. Для публичного доступа нужно разместить Python-приложение на сервисе, поддерживающем marimo, и подключить репозиторий. Не считайте публикацию завершённой, пока не проверена внешняя ссылка с другого устройства.

## Что есть на сайте

1. Цель исследования, описание тестовой части CIFAR-10 и случайных величин X и Y (средние HSV V и S).
2. Полные описательные статистики, boxplot, выбросы и дословные выводы из Colab.
3. Корреляции Пирсона и Спирмена, результат перестановочного теста на 2000 перестановках.
4. Модели распределений, сравнение AIC, Q–Q, KS, учёт 106 нулевых насыщенностей.
5. Стандартизация Z-score.
6. Два способа случайного отбора, изменяемый объём выборки, кнопка нового отбора, сравнение гистограмм и boxplot, RMSE по 300 повторениям.
7. Обработка **реальных HSV-пикселей** выбранного фото с пересчётом значений до/после.
8. Интерактивная диаграмма яркости и насыщенности с увеличением, наведением и выбором области.
9. Дополнительный датчик пар случайных чисел и сравнение с исходным распределением: эмпирический парный метод и независимые модели. Базовый датчик выбирается между PCG64, Park–Miller и историческим RANDU. По кнопке создаётся другая последовательность.
10. Дословный заключительный вывод из Colab и источники.

## Важные научные замечания

- **Генератор производит числа (X,Y), а не новые фотографии.** В эмпирическом парном методе индекс реального изображения выбирается как `floor(U * 10000)`, оба значения берутся из одной строки; это сохраняет наблюдаемую связь между величинами.
- В режиме **«Независимые теоретические модели»** яркость формируется по нормальной модели, ограниченной диапазоном `[0,1]`, через обратную функцию распределения; насыщенность — через смесь нулевой массы (1,06%) и бета-распределения для положительных значений. Такой режим **не сохраняет корреляцию** — это демонстрируемое ограничение, а не ошибка.
- Указанная KS для генератора — расстояние между эмпирическими распределениями, не автоматическое доказательство их равенства. KS для U(0,1) — диагностическая характеристика качества датчика, не полная проверка PRNG.
- Базовые итоговые цифры Colab рассчитаны для исходных 10 000 изображений. В интерактиве пользователь меняет **одну** фотографию, поэтому средние большой выборки могут меняться незначительно.
- Отдельный второй спринт команды (генераторы химических случайных величин) не заменяется этим дополнительным индивидуальным датчиком цветовых характеристик.

## Проверка перед сдачей

- Фон голубой на всю страницу, нет белых промежутков между разделами; SVG крылышек и цветочек видны.
- Фото № 72 или другое из списка отображается до/после; при изменении яркости/насыщенности меняется именно обработанное изображение.
- Кнопка новой выборки меняет значения корреляции и статистики, а режим с возвращением работает.
- Интерактивный график показывает подсказки при наведении и масштабируется.
- Оба режима генератора запускаются, графики и KS пересчитываются, а кнопка генерации меняет последовательность.
- Раскрывающиеся выводы и полный вывод внизу соответствуют `Photo (3).ipynb`.
